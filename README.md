# profit-lens

CLI tool for small business financial forecasting and valuation analysis

## Features

- **Cash Flow Forecasting**: Predict 3-6 months cash flow based on historical data and identify funding gaps
- **Break-Even Analysis**: Calculate minimum customers/MRR needed for SaaS businesses
- **Company Valuation**: Estimate acquisition price range using revenue multiple and DCF methods
